# Відповіді на контрольні запитання

**1. Що таке Google Colab?**
Хмарне середовище від Google для виконання коду на Python. Воно працює на базі Jupyter Notebook і надає безкоштовний доступ до обчислювальних ресурсів.

**2. Що таке Jupyter Notebook?**
Це інтерактивне середовище розробки, яке дозволяє об'єднувати виконуваний код, форматований текст (Markdown), графіки та результати обчислень в одному документі.

**3. Які два основні типи комірок використовуються в Notebook?**
Текстові комірки (Markdown) та комірки з кодом (Code).

**4. Як запустити комірку?**
Натиснути кнопку Play (трикутник) зліва від комірки або використати комбінацію клавіш `Shift + Enter` (чи `Ctrl + Enter`).

**5. Для чого призначений файл README.md?**
Для опису проєкту. У ньому вказують мету, автора, структуру файлів та інструкції. Він автоматично відображається на головній сторінці репозиторію в GitHub.

**6. Що таке pandas DataFrame?**
Це двовимірна структура даних у бібліотеці pandas (схожа на таблицю в Excel або базу даних), де дані організовані у рядки та стовпці.

**7. Що є рядком таблиці?**
Рядок представляє один окремий об'єкт дослідження (наприклад, одну конкретну квітку) з усіма його виміряними характеристиками.

**8. Що є стовпцем таблиці?**
Стовпець представляє одну конкретну ознаку (характеристику), яка виміряна для всіх об'єктів у таблиці.

**9. Що таке об’єкт у задачі машинного навчання?**
Це окрема одиниця дослідження (елемент набору даних), для якої ми збираємо дані, щоб навчити модель або зробити передбачення.

**10. Що таке ознака?**
Ознака (feature) — це індивідуальна вимірювана властивість або характеристика об'єкта.

**11. Що таке цільова змінна?**
Цільова змінна (target) — це те значення або категорія, яку наша модель машинного навчання має навчитися передбачати.

**12. Що є об’єктом у наборі Iris?**
Одна конкретна квітка ірису.

**13. Які ознаки містить набір Iris?**
Чотири числові ознаки: довжина та ширина чашолистка (sepal length/width), довжина та ширина пелюстки (petal length/width).

**14. Яка цільова змінна використовується у роботі?**
Вид квітки ірису (стовпець `species` — setosa, versicolor, virginica).

**15. Чому задача Iris є задачею класифікації?**
Тому що ми маємо передбачити не конкретне числове значення (як у регресії), а приналежність об'єкта до однієї з категорій (видів квітки).

**16. Чому ця задача є багатокласовою?**
Тому що наша цільова змінна містить більше двох можливих варіантів (у нас 3 види ірисів, а не 2).

**17. Для чого використовується метод head()?**
Для швидкого перегляду перших рядків таблиці (за замовчуванням перших п'яти).

**18. Для чого використовується метод tail()?**
Для перегляду останніх рядків таблиці (за замовчуванням останніх п'яти).

**19. Що повертає властивість shape?**
Вона повертає розміри таблиці у вигляді `(кількість рядків, кількість стовпців)`.

**20. Для чого використовується метод info()?**
Для отримання загальної технічної інформації про DataFrame: кількості непорожніх значень, типів даних у кожному стовпці та обсягу використаної пам'яті.

**21. Яку інформацію повертає метод describe()?**
Він повертає описову статистику для числових стовпців: середнє значення, мінімальне і максимальне значення, стандартне відхилення та квартилі.

**22. Як знайти пропущені значення?**
За допомогою методу `isna()` або `isnull()`, зазвичай у поєднанні з `sum()` для підрахунку: `data.isna().sum()`.

**23. Як перевірити наявність дублікатів?**
За допомогою методу `duplicated()`, додавши `sum()`: `data.duplicated().sum()`.

**24. Для чого використовуються гістограми?**
Для візуальної оцінки розподілу числових даних, щоб побачити частоту появи різних значень, форму розподілу та можливі викиди.

**25. Чому важливо аналізувати розподіл об’єктів за класами?**
Щоб перевірити, чи збалансований набір даних. Якщо класів не порівну, модель може навчитися погано розпізнавати "менший" клас.

**26. Чим ознаки X відрізняються від цільової змінної y?**
`X` (ознаки) — це вхідні дані, на основі яких робиться висновок, а `y` (цільова змінна) — це результат (відповідь), який модель намагається вгадати або спрогнозувати.

**27. Чому важливі дані потрібно зберігати на Google Drive або GitHub?**
Бо середовище Google Colab є тимчасовим. Як тільки сеанс завершується, всі завантажені у Colab файли безповоротно видаляються.

**28. Чому перед здаванням необхідно повторно виконати всі комірки?**
Щоб переконатися, що код працює стабільно згори донизу, немає прихованих помилок, а всі графіки та таблиці відповідають фінальному варіанту коду.

**29. Які файли містить створений навчальний ML-проєкт?**
Папку `notebooks` (із файлом Notebook .ipynb), папку `data` (із файлом iris.csv), папку `reports` (порожню або зі звітом), а також файли `README.md` та `.gitignore` у корені.
