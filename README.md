## Опис проєкту

Стартова персоналізована сторінка: профіль студента з аватаром, індивідуальний колір-акцент (CSS-змінна `--accent`), унікальний ідентифікатор сторінки, що генерується у `main.js`, та персональне вітання в консолі браузера.

## Структура

- `index.html` — розмітка сторінки
- `styles/style.css` — стилі
- `scripts/main.js` — генерація PageID, вітання в консолі
- `assets/img/` — зображення (аватар)
